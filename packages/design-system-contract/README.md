# @fireflyframework/design-system-contract

Contract package for design-system metadata and compatibility rules.

## Current status

This package is still scaffold-level. The current public API exports a placeholder `designSystemContract()` function from `src/lib/design-system-contract.ts`.

Do not treat this package as a stable consumer-facing API until its relationship with `@fireflyframework/design-system` is finalized.

## Expected documentation before stabilization

- What contract this package owns: tokens, component metadata, compatibility rules, schema types, or all of them.
- How it differs from `@fireflyframework/schema-types`.
- How design-system implementations and products consume the contract.
- Versioning expectations between this package and `@fireflyframework/design-system`.

## Commands

```bash
nx build design-system-contract
```
