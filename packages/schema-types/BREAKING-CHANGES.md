# Breaking Changes

Cumulative log of breaking changes in `@fireflyframework/schema-types`, with migration notes for consumers.

For the full per-release history (including non-breaking changes), see [CHANGELOG.md](CHANGELOG.md).

## How to read this file

- Entries are grouped by version, newest first.
- Every entry states: what changed, why, and the migration path (before / after).
- Pre-1.0 versions may include breaking changes inside minor bumps; they are still listed here.
- For this package (types-only, no runtime), breaking means: renaming/removing a top-level type, adding a required field to an exported type, narrowing a union, or changing the DSL meaning of a field.
