# @fireflyframework/elements

Package reserved for Firefly elements.

## Current status

This package is still scaffold-level. The current public API exports a placeholder Angular component, `Elements`, with selector `lib-elements`.

Do not treat this package as a stable consumer-facing API until the elements strategy is defined.

## Expected documentation before stabilization

- Whether this package will expose Angular elements, web components, or product embeddables.
- Build and registration strategy.
- Browser compatibility and polyfill expectations.
- Relationship with `@fireflyframework/design-system`.

## Commands

```bash
nx build elements
nx lint elements
```
